# Tavern Flight Recorder 0.1.0

独立的 SillyTavern / TauriTavern 轻量诊断扩展，用于调查高负载时整页重载。无需 Claude Surface，无外部依赖，无远程上传。

## 安装

在酒馆「扩展程序 → 安装扩展」粘贴：

```text
https://github.com/lolo-desu/tavern-flight-recorder
```

安装后刷新一次。在「扩展程序」设置中找到 **Tavern Flight Recorder · 轻量诊断**，确认显示「正在记录」。如有需要，填写 TauriTavern / iOS 版本。

## 收集与导出

1. 正常使用，等待原来的问题出现。
2. 页面重载回来后，打开扩展设置，点「标记刚发生的问题」。
3. 点「导出日志文件」，保存 `tavern-diagnostics-日期.json`，将文件发给调查者。iOS 根据宿主实现可能打开系统下载或文件保存界面。

导出后记录仍然保留。可暂停「记录诊断日志」，或使用「清除诊断日志」清理本扩展的数据。不要在导出前清除酒馆网站数据或卸载 App，那会删除本地记录。

## 记录内容

- 页面每次启动、是否正常离开、前后台切换、网络在线状态、页面恢复，以及同一标签页上一次记录是否缺少正常结束事件。
- 每 5 秒保存一次；后台间隔为 15 秒，并在生命周期变化时立即保存。换聊天、消息切换/编辑等事件按计数合并，额外检查点最多每 2 秒触发一次。
- 顶层页面中的消息、iframe、停车 iframe、canvas、video 数量和视口尺寸。不会访问 iframe 内部页面。
- 主页面错误类型、来源类别、行列号和错误指纹。错误原文和堆栈不会保存；错误风暴受限流保护。
- 系统与引擎版本、屏幕尺寸；若浏览器支持，则记录 JS 堆和长任务汇总。**iOS 通常不提供 JS 堆/长任务指标，缺失不代表内存使用为零。**

## 边界与隐私

这是提前保存的运行轨迹。网页进程被系统直接杀掉时，JavaScript 没有机会补写最后一条；最后几秒可能缺失，本地存储也不能保证在所有系统崩溃情况下完成落盘。缺少正常结束事件只是一条线索，普通关闭、后台回收也可能导致它。

网页扩展无法读取 iOS JetsamEvent，也无法取得原生 WKWebView 的进程终止原因。最终确认 OOM 或 WebKit 崩溃仍可能需要系统诊断文件。

不记录聊天正文、角色名称、提示词、请求/响应、API 密钥、完整网址、错误原文、iframe 内容或自定义脚本内容。不接管 console、fetch、XHR，不注入 iframe，不添加 DOM MutationObserver。**没有服务器，不自动上传。** 日志只存本机，用户主动导出后自行发送。

最多保留最近 6 次页面启动，每次最多 240 条事件及 24,000 字符；按 UTF-16 估算记录键值约 300 KB 上限，不含浏览器内部存储开销。暂停和清除只操作本扩展的存储前缀。

## 手动安装

把包含 `manifest.json`、`index.js`、`core.mjs`、`style.css` 的整个文件夹放到酒馆第三方扩展目录。使用 Git URL 安装更方便更新。

## 验证

核心模块覆盖异常中断后恢复、普通页面离开/bfcache、存储配额失败、暂停与清除、容量上限、跨标签页区分和字段白名单测试。完整 iOS 崩溃恢复仍需真机复测，不通过故意耗尽设备内存测试。
